#   identity     an identity of algebra hides the change: a sum of (v + m)(v - m) about the
#                mean m is the sum of squares; a vector that enters as a square may change
#                sign; a regression that holds x spans the same columns with x + f as with x - f
#   scale        a scale by which columns are brought to unit size before a factorisation; the
#                statistic does not depend on it (held by a test under a change of units)
#   fence        a second fence behind a first that decides: the checker or an earlier refusal
#                comes before, an outer comparison shortcuts an inner one, or a later step
#                refuses what this one let through
#   guard        a guard or a self-check against the engine's own faults, which ends in Z9001
#                and which correct code never fails
#   margin       a bracket, a reach, a tolerance or a stopping rule with room to spare, whose
#                change moves no digit that a test holds or could hold
#   edge         a comparison at a value that is never met exactly
