## Questions only the owner can answer

1. **Weighted statistics (`weights:` with `weight_type: frequency | analytic | sampling`).** Section 6 gives statistics `weights:` but not the formulas. Recommendation: frequency weights replicate rows (N is the sum of the weights, the variance divisor is that sum less one); analytic and sampling weights give the weighted mean Σwx/Σw and, as Stata's `summarize [aweight]`, a variance with weights scaled to sum to n and divisor n − 1; `sum` with sampling weights is the weighted total Σwx; `median` and `quantile` use the cumulative weight; `n` is the row count with analytic and sampling weights and the weight sum with frequency weights. Needed at step 17.
2. **The synthetic `wages` dataset.** Section 8.5 asks for a generated dataset with documented true parameters (a return to education of 0.074) and section 10.2 illustrates its 13 variables and panel shape (18,412 rows). Recommendation: I draft the generating model (variables, distributions, coefficients, the panel of workers over years, the missing-value pattern) for the owner's approval before step 18; until `draw` exists (0.3.0) it is generated by a committed Python script with a fixed seed, and regenerated by a Zeff script at 0.3.0 under a new name if the values change. Needed at step 18.
3. **Open decision #45, due at this release.** Whether a warning printed under a result shows its code (`warning[W0201]: …`) or reads as section 10.2 prints it (`warning: …`). Recommendation: as section 10.2, without the code, until the pragma `// zeff: allow(CODE)` arrives at 0.7.0; the code is in `--format json` from this release. Needed at step 8.

## Rulings taken from the specification (engineering; each recorded in `docs/decisions.md` in the step that needs it)

- The elementary functions come from the `libm` crate (a pure-Rust port of musl's maths library, MIT), compiled into the engine and used on every target, which is what section 8.3, point 3 asks for; `sqrt` is IEEE's own and correctly rounded everywhere. Accuracy against R's values is within the closed-form class; identity across targets is exact.
- Fuzzing uses `cargo-fuzz` with a nightly toolchain in the nightly job only; the engine's toolchain stays pinned stable. The fuzz targets live in `fuzz/`, outside the workspace's engine crates.
- The explained-code pages are Markdown files compiled into the engine like help pages, one per code the engine raises, checked at `cargo test` so that a code without a page fails the build; `zeff explain` (the command) arrives at 0.8.0, so at 0.2.0 the pages are read with `zeff help Z0101`.
- `--format json` carries each diagnostic's code, span, message, help and fixes; `--width` sets the page width that frames and tables wrap at (118 by default); `--ascii` replaces `·`, `×`, `…` and `→` with ASCII; `--quiet` hides notes; `--color` follows `NO_COLOR` and the terminal.
- The console keeps the session script `.zeff/session.zeff`; `:undo` re-runs the session without the last statement (the result cache is 0.11.0). Outside a project the scratch project is `~/.zeff/scratch/` (`ZEFF_HOME` honoured).
- The `datasets` package embeds the datasets under one megabyte in the engine (CSV and Parquet) and resolves the `zeff:` data root to them, so the browser needs no fetch; larger datasets and `zeff dataset fetch` wait for the registry (after 1.0). `parquet` (pinned at 0.1.0, not linked) is linked in `zeff-columns` for `dataset(name)`.
- R is installed through Homebrew locally and `r-lib/actions/setup-r` in CI, pinned to one version, with `renv.lock` for the packages; its scripts write JSON beside Python's, and the test compares with both.
- Grouping (`by:`) builds a group index by the identity rules of section 3.7 (NA its own group, `-0.0` with `0.0`), groups in key order with NA last, never by hash order; the index is reused by every reducer in one call.
- `aggregate`, `tabulate`, `distinct`, `label`, `recode`, `merge`, `append`, `to_long`, `to_wide`, `panel`, `save`, `category`, `to` and the `text` and `time` packages are later releases and are not pulled forward; a call to one of them stays Z0304 "arrives with release X".
