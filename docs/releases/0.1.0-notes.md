# Zeff 0.1.0 — First engine

Released 18 October 2026. The first release of the Zeff engine: a Cargo workspace laid out by
package and tier, the lexer and parser for the whole grammar, the typed intermediate form with
diagnostics as data, Arrow columns, projects with `zeff.toml`, CSV import, the function registry
compiled from the help pages, the first five commands, continuous integration on four targets with
the bit-identity check from the first commit, and ten functions, each with its complete help page.
It runs one real analysis end to end: read a CSV file, look at it, and summarise it.

## What shipped

**Commands.** `zeff new <name>` creates a project (`zeff.toml`, `scripts/main.zeff`, `data/`);
`zeff run [script]` runs a script, output on stdout and messages on stderr, stopping at the first
error (exit code 1; 4 when the project pins another engine); `zeff check [script]` checks names,
arguments and types and reports every problem; `zeff help <name>` prints a function's page, lists a
shipped package, or says when a later function arrives; `zeff version`.

**Language.** Every token and the whole grammar of the Language Reference, section 3, are parsed;
what 0.1.0 does not yet run (`fn`, `for`, `use`, `case`, `if`, `model`, `dag`, operators over
values) is refused with a diagnostic that names the release it arrives with. `let` bindings,
literals, lists and records, calls and method chains, options and definitions run. A statement that
is not a `let` prints its value by the rules of section 3.8: an Int in full, a Float to six
significant digits, a frame as its header and first ten rows, a table as its title and aligned
rows, lists one item per line. Warnings and notes print under the output they belong to, with the
line they come from.

**Diagnostics.** Rust-style messages with the code, the file, the line and column, the offending
text marked, and a help line: 60 codes are raised at this release (names, syntax, the project file,
arguments, CSV import, paths, the reducers' warnings), each with a snapshot test of its wording.

## Functions by package

**core (tier 0), 1 of 68.**

- `print` — print values, any number of them, each as it prints on its own.

**data (tier 1), 9 of 59.**

- `frame` — a frame from named lists of values.
- `import` — a CSV file into a frame, with `delim:`, `header:`, `skip:`, `na_values:`, `types:`
  and `names:`; types guessed from the first 1,000 rows, dates read in ISO form or with a declared
  format, one note saying what the format carried.
- `n_rows`, `n_cols`, `variables` — the shape and the names of a frame.
- `describe` — type, non-missing and missing count and an example for each variable.
- `mean` — the mean of a variable, missing values skipped and counted; a Bool column gives the
  share of `true`.
- `sd` — the sample standard deviation (n − 1), two-pass with scaled deviations.
- `summary` — the table of N, missing, mean, sd, min and max for chosen variables and chosen
  statistics.

## Breaking changes

None: this is the first release. Before 1.0 a release may change the language; each change will be
listed here with the rewrite it needs.

## Reference versions

- Python 3.14.8, `statistics` module (exact rational arithmetic) for means, standard deviations,
  minima and maxima; `csv` module for the splitting of CSV files. The scripts and their stored
  outputs are in `tests/reference/`, re-run by CI on every push.
- No R or Stata output at this release; the R scripts of the testing handbook begin with 0.2.0.

## Validation

- 423 tests pass on every push (unit, reference, edge-case, property, snapshot, help, script);
  format, clippy with warnings denied and the tier rule enforced.
- Bit-identity: the conformance report (36 numeric cases, four canaries, the milestone script and
  the sample project) is identical on Linux x86-64 at the baseline and at the x86-64-v3 instruction
  level, Linux ARM64, macOS ARM64 and WebAssembly (SIMD128) under Node 24. No run of the release
  showed a cross-target difference.
- The sample project `samples/first_engine/` runs to its stored output byte for byte on every
  target.
- Coverage: 94.6% of the kernel's 2,553 lines; 94.0% of the workspace. Mutation testing of
  `zeff-numeric`: 99 mutants, 93 caught, none missed, 6 timed out.
- Browser build: the compressed engine bundle is 355 kB (brotli; 444 kB gzip; 1.26 MB raw) against
  the 5 MB limit of risk R4; cold start 21 ms against 1,000 ms.
- Build: a clean release build of the workspace takes 23 s on the development machine.

## Known issues

See `docs/known_issues.md`; as of this release: printed widths count characters (East Asian wide
characters misalign a table); `summary` prints fixed three-decimal statistics; CSV dates only in ISO
form or with a declared format; no `by:` on the statistics; a line beginning with `-` is refused;
`import` reads CSV only; projects pin the exact engine version and there is no launcher yet.

## Decisions due at this release
