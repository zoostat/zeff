Zeff is a statistics language for empirical and causal research. Statistics are built in: frames, formulas, model blocks and results are language types, not add-ons, and every model is one statement. It is reproducible by default: a project re-runs to identical numbers on any machine, and nothing is dropped or skipped without a report. The language and engine are written in Rust, compiled to WebAssembly for the browser and to native code for the command line, and are licensed under Apache 2.0.

Zeff is pre-release software. Version 0.1.0 is in development, and nothing in this repository should yet be relied on for real analyses.
