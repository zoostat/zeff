# datasets

## Summary
Table of the shipped datasets

## Description
The datasets that ship inside the engine, one row each: the name to give `dataset`, the rows and
columns, the kind (public, with a stated licence and source, or synthetic, generated by a committed
script with documented true parameters), the licence, the source and the size of the files. Like
R's `data()` and Stata's `sysuse dir`.

## Arguments

## Value
A `Table`.

dataset, import
