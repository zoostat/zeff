# datasets

## Summary
Table of the shipped datasets

## Description
The datasets that ship inside the engine, one row each: the name to give `dataset`, the rows and
columns, the kind (public, with a stated licence and source, or synthetic, generated by a committed
script with documented true parameters), the licence, the source and the size of the files.

## Arguments

## Value
A `Table`.

## Coming from R or Stata
| datasets() | data() | sysuse dir |

R's `data()` lists the datasets of the packages that are loaded; here the list is of the
datasets inside the engine, the same on every machine.

## Related tasks
- To load one of them, use `dataset`.
- To read a file of your own, use `import`.

## See also
dataset, import
