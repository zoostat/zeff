# Z0602 — a panel function without a panel

## Meaning
`lag`, `lead`, `diff` or `fill_forward` was called where it cannot follow a unit's time order: outside `add` or `update`, or inside them on a frame that has no panel declaration. These functions take the unit and the time from the panel, never from the row order, so that a gap in time gives `NA` as Stata's `L.` does.

## Common causes
- A frame never declared: `wages.add(prev = lag(wage))` before `wages.panel(unit: worker, time: year)`.
- A declaration lost on the way: a `select` that left out the time variable, or an `aggregate`, drops it with a note.
- The function applied to a column outside a frame method: `lag(wages["wage"])`.

## Example
```
> let w = import("data/wages.csv")
> w.add(prev = lag(wage))
error[Z0602]: `lag` needs a panel, but `w` has no declaration
  = help: declare the panel first: `data.panel(unit: firm, time: year)` (section 6 of the Language Reference)
```

## Fix
Declare the panel with `panel(unit:, time:)` and write the function inside `add` or `update`; `fill_forward` alone also works without a declaration, following the row order or the `by:` groups.
