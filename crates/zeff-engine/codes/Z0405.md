# Z0405 — an argument given twice

## Meaning
The same argument or definition appears twice in one call.

## Common causes
- A positional argument and the same one by name.
- Two `by:` options.

## Example
```
> import("data/wages.csv", skip: 1, skip: 2)
error[Z0405]: `skip:` is given twice
```

## Fix
Keep one of the two.
