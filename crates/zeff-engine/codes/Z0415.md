# Z0415 — a restriction test cannot use

## Meaning
`test` takes restrictions that are equalities linear in the coefficients, such as `educ == exper` or `educ + exper == 1`, and tests them together. The restriction given is not one: it multiplies or divides coefficients, raises one to a power, calls a function, uses `<`, `!=` or `&&`, or holds no coefficient at all; or the restrictions repeat one another, so that their covariance matrix is singular.

## Common causes
- A product or ratio of coefficients: `educ * exper == 0`, `educ / exper == 1`.
- A term written without backticks: `exper^2 == 0` reads as the square of `exper`; the term is `` `exper^2` ``.
- Two restrictions in one argument with `&&`.
- The same restriction twice, or one implied by the others.

## Example
```
> m.test(educ / exper == 1)
error[Z0415]: `educ / exper == 1` is not a linear restriction on the coefficients: a division by a coefficient
  = help: `test` takes equalities linear in the coefficients, `educ == exper` or `educ + exper == 1`; `derive` computes a nonlinear combination with its standard error
```

## Fix
Rewrite the restriction as a linear equality, one per argument; for a nonlinear quantity use `derive`, which gives its estimate and standard error.
