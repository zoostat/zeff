# Z0315 — a token from another language

## Meaning
`;`, `&`, `|`, `**`, `%`, `<-`, `TRUE`, `FALSE`, `NULL`, `None`, single quotes and `=` where a comparison was meant are syntax errors with the Zeff form named.

## Common causes
- R or Python written from habit.

## Example
```
> x <- 1
error[Z0315]: `<-` is not used in Zeff
  = help: write `let x = 1`
```

## Fix
Write the Zeff form the help line names.
