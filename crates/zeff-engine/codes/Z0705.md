# Z0705 — the run was cancelled

## Meaning
The run was stopped from outside while it was going, by the program that started it. A run is cancelled between its steps, so the statement that was running finished first, and the run stopped before the next statement, or before the next pass of a loop. Nothing after that point ran. What ran before it stays: its output is printed, and in a session its bindings are there to use (section 8.3 of the Engine and Project Specification, point 7).

## Common causes
- A long run stopped on purpose, to change the script and run it again.
- A loop over many draws that was taking longer than expected.

## Example
```
> zeff run
error[Z0705]: the run was cancelled before this statement
```

## Fix
Nothing is wrong with the script. Run it again when ready. The exit code is 1.
