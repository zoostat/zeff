# Z0702 — a path that differs only in case from the file's name

## Meaning
The path written differs from the file's real name only in upper and lower case. It would work on some systems and not on others, so Zeff refuses it everywhere.

## Common causes
- `data/Wages.csv` for `data/wages.csv`.

## Example
```
> import("data/Wages.csv")
error[Z0702]: path `data/Wages.csv` differs only in case from `data/wages.csv`
```

## Fix
Write the path exactly as the file is named.
