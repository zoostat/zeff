# Z0207 — an index outside the list

## Meaning
A list was indexed outside its positions, which count from 1 to its length, or with `NA`; a range with an `NA` end is the same error.

## Common causes
- An off-by-one: `xs[0]`, or `xs[len + 1]`.
- An index computed from a value that was `NA`.

## Example
```
> [10, 20, 30][4]
error[Z0207]: index 4 is outside 1..3
```

## Fix
Positions count from 1; check the length first, or the value the index came from.
