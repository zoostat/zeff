# Z0605 — a header the reader cannot use

## Meaning
The CSV file's first row cannot name the columns: it is missing, a name is empty, a name is repeated, two names differ only in case, or `names: snake` would give two columns the same name.

## Common causes
- An empty file.
- A spreadsheet export with an unnamed column.
- `Wage` and `wage` in one file.

## Example
```
> import("data/f.csv")
error[Z0605]: `data/f.csv` has two columns called `x` (positions 1 and 3)
```

## Fix
Fix the names in the file, or read without names (`header: false`) and rename afterwards.
