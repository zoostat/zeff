# Z0409 — a bad date format

## Meaning
`Date("...")` or `DateTime("...")` was given a format that is not one (an unknown `%` directive), or a `Date` format with a time in it.

## Common causes
- `%Q` or `%i` where `%m` was meant.
- `Date("%d/%m/%Y %H:%M")`: a format with a time is a `DateTime`.

## Example
```
> import("d.csv", types: {sold: Date("%d/%m/%Q")})
error[Z0409]: `%d/%m/%Q` is not a date format
```

## Fix
A format uses `%Y`, `%y`, `%m`, `%b`, `%d`, `%H`, `%M` and `%S`, as in `Date("%d/%m/%Y")`.
