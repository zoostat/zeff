# Z0416 — two regressions that cannot be compared

## Meaning
`compare` tests the terms one regression adds to another, so the two must be fitted on the same rows and one must be nested in the other: every term of the smaller model a term of the larger, and the larger holding at least one more.

## Common causes
- A variable with missing values in one model only, so the fits used different rows.
- Two models with the same terms.
- Models that each hold a term the other lacks.

## Example
```
> m2.compare(m1)
error[Z0416]: `compare` needs two regressions on the same rows, but these used 18,179 and 18,201 rows
  = help: fit both models on one frame with the same rows; `where(!is_missing(x))` first keeps the rows a variable of one model would drop
```

## Fix
Fit both models on one frame after dropping the rows with missing values, and make sure the smaller model's terms are all in the larger.
