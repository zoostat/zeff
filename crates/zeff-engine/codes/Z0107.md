# Z0107 — a name defined twice

## Meaning
A script's functions share one namespace, so a function defined twice in one file is an error at the second definition. From release 0.5.0's modules, two imported modules that define the same name are the same error at the second `use` (section 5.3, "Modules"), until the name is written in full, `clean::share_missing`.

## Common causes
- A helper copied and not renamed.
- Two modules written separately that both define a common name.

## Example
```
> fn share(data: Frame) -> Float { 0.5 }
> fn share(data: Frame) -> Float { 0.25 }
error[Z0107]: `share` is defined twice in this file
  = help: give each function its own name; a script's functions share one namespace
```

## Fix
Rename one of the two; for modules, write the name in full.
