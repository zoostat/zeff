# W0205 — an operation with no value gave NA

## Meaning
`0 / 0`, `Inf - Inf`, `Inf * 0`, a power with no real value, the standard deviation of one value or of a column holding an infinity: the result is `NA`, with the cause named and, for a column, the count of rows.

## Common causes
- Two zeros divided, often from counts that are both zero.
- Infinities from an earlier step meeting in a subtraction or a product.
- `sd` on a variable with one value left after the missing ones.

## Example
```
> 0 / 0
NA
warning: 0 / 0 gave NA (line 1)
```

## Fix
Trace where the zeros or infinities come from; a `where` that drops those rows, or a different formula, usually removes the case.
