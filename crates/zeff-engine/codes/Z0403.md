# Z0403 — a word written as text

## Meaning
An argument takes a bare word, but it was written in quotes.

## Common causes
- `se: "robust"` for `se: robust`.

## Example
```
> wages.summary(stats: ["mean"])
error[Z0403]: expected one of n, missing, mean, sd, min, max, found text
  = help: write the word without quotes: `mean`
```

## Fix
Remove the quotes.
