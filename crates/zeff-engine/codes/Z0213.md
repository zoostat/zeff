# Z0213 — a field was read from something that is not a record

## Meaning
`.name` without parentheses reads a record's field. On any other value it is a mistake, usually a method call missing its parentheses.

## Common causes
- `wages.describe` for `wages.describe()`.
- `x.a` where `x` is a number.

## Example
```
> let n = 3
> n.a
error[Z0213]: `.a` reads a record field, but this is an Int
  = help: a method call has parentheses: `.a()`
```

## Fix
Add the parentheses for a method, or read a field of a record.
