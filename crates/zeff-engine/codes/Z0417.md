# Z0417 — a definition derive cannot differentiate

## Meaning
`derive` evaluates each definition at the estimates and differentiates it over the coefficients for the delta-method standard error. It differentiates `+`, `-`, `*`, `/`, `^`, `log`, `exp`, `sqrt`, `log1p`, `expm1`, `log10`, `log2` and `abs`; anything else in a definition, a comparison, a function of two arguments, a rounding, text, has no derivative here.

## Common causes
- A comparison or a logical operator in a definition.
- A function that is not smooth, such as `round`, or one of two arguments.

## Example
```
> m.derive(r = round(educ / exper))
error[Z0417]: `round(educ / exper)` cannot be differentiated: `round` cannot be differentiated
  = help: `derive` differentiates `+`, `-`, `*`, `/`, `^`, `log`, `exp`, `sqrt`, `log1p`, `expm1`, `log10`, `log2` and `abs` over the terms
```

## Fix
Write the quantity with the arithmetic and functions listed; round the printed result afterwards if needed.
