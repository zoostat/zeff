# Z0210 — a date compared with text

## Meaning
A `Date` or `DateTime` was compared with text. Text never becomes a date on its own (section 3.7 of the Language Reference, "No implicit conversion"), so `sold > "2020-01-01"` compares two different kinds of value.

## Common causes
- A date written in quotes beside a date variable: `where(sold > "2020-01-01")`.
- A text column that holds dates, never converted: `import` reads a column as `Date` only when its values are ISO 8601 or `types:` names the format.

## Example
```
> let sales = frame(sold = [to("2020-03-01", Date)])
> sales.where(sold > "2020-01-01")
error[Z0210]: `>` compares a Date with text
  = help: write the text as a date: `to("2020-01-01", Date)`, or `date("2020-01-01")` from the `time` package
```

## Fix
Write the text as a date, `to("2020-01-01", Date)` or `date("2020-01-01")`, or convert the text column first, `to(sold, Date)`.
