# Z0704 — a step would pass the memory budget

## Meaning
The run has a memory budget, set by `memory` under `[project]` in `zeff.toml` or by `--memory`, and the statement was not started because the memory it may need, added to what the run already holds, is more than the budget. The figure is an estimate made before the statement runs, and an upper bound: a file is counted as held whole while its columns are built, and a statement that builds a frame from others as needing those frames once more. The statements before it ran; nothing after it did (section 8.3 of the Engine and Project Specification, point 7).

## Common causes
- A file too large for the budget, read with all its columns.
- Several large frames kept at once, where one would do.
- A budget set low for a small machine, on a script written for a larger one.

## Example
```
> zeff run --memory 64KB
error[Z0704]: this statement may need 1.6 MB of memory, more than the budget of 64.0 kB
```

## Fix
Read less: `import(..., columns: [...])` reads only the columns named, and `select` keeps only those wanted. Or raise the budget, with `--memory 2GB` for one run or `memory = "2GB"` in `zeff.toml` for the project, where the machine has the memory. The message lists what the estimate is made of. The exit code is 1.
