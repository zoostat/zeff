# Z0225 — a function's result does not match its declared type

## Meaning
A function declares what it returns, `-> Float`, and its body's last expression and every `return` give that type (section 3.7, "Inference"; section 5.3). A body that ends in a `let`, a `for` or an `if` without `else` gives nothing, which is this error too unless the function is declared `-> Nothing`.

## Common causes
- A body whose last line is a `let`, so nothing is returned.
- Text returned from a function declared to return a number, or an Int list from one declared `List<Float>`.
- `return` without a value in a function that returns something.

## Example
```
> fn share(data: Frame) -> Float {
>     let n = data.n_rows()
> }
error[Z0225]: `share` is declared to return a Float, but its body ends without a value
  = help: end the body with the expression that is the result, or `return` it; a body ending in a `let`, a `for` or an `if` without `else` gives nothing
```

## Fix
End the body with the value, or change the declared type; Int is accepted where Float is declared.
