# Z0803 — an outcome too large to compute with

## Meaning
A regression squares its outcome: the residual sum of squares, the standard errors and R² all need it. A value above 1e150 in size has a square the machine cannot represent, so the fit would end in infinities. Zeff refuses the fit and says which variable it is. A regressor of that size is not an error: it is dropped from the model with a note, as a regressor below 1e-150 is.

## Common causes
- A variable in units that make its values astronomically large, such as a currency amount in the smallest unit over a long span.
- A code for a missing value, such as `1e300`, that was not declared with `na_values:`.

## Example
```
> let d = frame(y = [0.5, 1e300, -1, 2], x = [1, 2, 4, 3])
> d.reg(y ~ x)
error[Z0803]: `y` has values too large to compute with (above 1e150 in size)
  = help: divide the outcome by a power of ten first, `add(y_m = y / 1e6)`, and read the estimates in those units
```

## Fix
Rescale the outcome before fitting, `add(y_m = y / 1e6)`, and read the estimates in those units; or declare the code for a missing value with `import(..., na_values: [1e300])`.
