# Z0803 — an outcome too large or too small to compute with

## Meaning
A regression squares its outcome: the residual sum of squares, the standard errors and R² all need it. A value above 1e150 in size has a square the machine cannot represent, so the fit would end in infinities; an outcome so small against its regressors that an estimate falls below 2.2e-308, the smallest normal number, keeps only a few digits of that estimate, so the fitted values would be wrong in their leading digits. Zeff refuses the fit either way and says which variable it is. A regressor above 1e150 or below 1e-150 in size is not an error: it is dropped from the model with a note.

## Common causes
- A variable in units that make its values astronomically large, such as a currency amount in the smallest unit over a long span.
- A code for a missing value, such as `1e300`, that was not declared with `na_values:`.
- An outcome in units that make its values vanishingly small against a regressor of large units, such as a probability raised to a high power against a count in the millions.

## Example
```
> let d = frame(y = [0.5, 1e300, -1, 2], x = [1, 2, 4, 3])
> d.reg(y ~ x)
error[Z0803]: `y` has values too large to compute with (above 1e150 in size)
  = help: divide the outcome by a power of ten first, `add(y_m = y / 1e6)`, and read the estimates in those units
```

## Fix
Rescale the outcome before fitting, `add(y_m = y / 1e6)` for a large one or `add(y_k = y * 1e6)` for a small one, and read the estimates in those units; or declare the code for a missing value with `import(..., na_values: [1e300])`.
