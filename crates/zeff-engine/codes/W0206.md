# W0206 — a key of `recode` matches no value or level

## Meaning
`recode(var, [old => new, ...])` replaces each old value, or merges each old level, that the variable holds. A key that no row holds, or that is no level of the category, changes nothing, and this warning names it so that a misspelt level or a key of the wrong type is not passed over in silence, as forcats warns of unknown levels. The other keys are applied.

## Common causes
- A level misspelt: `["Utilites" => "Other"]` for `Utilities`.
- A key of another kind than the values: `["1" => "one"]` on an Int variable is refused outright, but `[1.5 => 2]` on a Float variable that holds no 1.5 is this warning.
- A recoding written for another file's categories.

## Example
```
> let w = dataset(wages).recode(industry, ["Mining" => "Other", "Utilites" => "Other"])
warning: `recode`: "Utilites" is not a level of `industry`
  = help: `levels(industry)` lists the levels; the other keys were applied
note: `industry` recoded: 200 rows changed; 11 levels, from 12
```

## Fix
`levels(x)` lists a category's levels and `describe` shows a variable's example value; correct the key, or remove it.
