# W0303 — a function without a summary line

## Meaning
`///` lines directly above a `fn` are its help: the first is the summary shown in completion, in hover text and as the title of its Zemp dialog (section 5.3, "Help"). A function in a script needs that one line; a module in `functions/` needs the complete page (Z0319). The script runs without it.

## Common causes
- A helper written quickly.
- A blank line between the `///` text and the `fn`, which detaches it (and is Z0318).

## Example
```
> fn double(x: Float) -> Float { x * 2 }
warning[W0303]: `double` has no summary line
  = help: write one line above it, `/// What the function gives.`; the line is its help, its hover text and the title of its dialog
```

## Fix
Write one line of `///` text directly above the `fn`.
