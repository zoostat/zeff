# Z0220 — a failed value used outside a list

## Meaning
`attempt(expr)` returns a `Failed` value when `expr` stops with an error. Such a value may sit in a list, where `report` and `len` skip it with a count; used anywhere else, as an argument, in arithmetic, in a record or as a model input, it is this error, which reports the failure it holds: its code, line and message.

## Common causes
- `let m = attempt(d.reg(y ~ x))` followed by `m.coef(x)` when the fit failed; the checker warns about this (W0209).
- A list from `[for ...]` with `attempt` given to a function other than `report` or `len`.
- Arithmetic on a value from `attempt`.

## Example
```
> let m = attempt(w.where(wage > 1000).reg(log(wage) ~ educ))
> m.coef(educ)
error[Z0220]: a failed value cannot be used as an argument: it failed with Z0801 at line 1: no row remains once the rows with NA are dropped
  = help: test it first with `x.is(Failed)`, or keep it in a list for `report` and `len` to skip with a count (section 5.4)
```

## Fix
Test the value with `x.is(Failed)` and skip or stop when it failed, or keep the values in a list for `report` and `len`.
