# Z0310 — a malformed number

## Meaning
A number is written in a form Zeff does not read: `.5` or `5.` (write `0.5` and `5.0`), a leading zero before another digit (`007`), an integer beyond 64 bits, or `_` where it may not stand.

## Common causes
- `.5` copied from R output.
- `1_000_` with a trailing separator.

## Example
```
> let x = .5
error[Z0310]: `.5` is not a number
  = help: write `0.5`
```

## Fix
Write the number in the accepted form the help line shows.
