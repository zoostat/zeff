# Z0301 — a character or token that does not belong here

## Meaning
The text has something the grammar does not allow at that place: a character that is not part of Zeff (`#`, `$`, `@`), an empty or unclosed backtick name, or a token the parser did not expect.

## Common causes
- `#` for a comment: Zeff's comments begin with `//`.
- A missing comma between arguments.
- A stray character from another language.

## Example
```
> # a comment
error[Z0301]: unexpected character `#`
  = help: a comment begins with `//`
```

## Fix
Follow the help line, which names the Zeff form.
