# Z9001 — an internal error: a bug in Zeff

## Meaning
Something failed inside the engine itself, not in the script: an invariant the engine relied on did not hold. The run stops at that statement with exit code 2; the statements before it ran. This is never the user's fault.

## Common causes
- A bug in a function body or in the engine's own tables.

## Example
```
> wages.mean(wage)
error[Z9001]: internal error: this is a bug in Zeff, not in your script (...)
```

## Fix
Please report it with the script and the data that led here; the bug-report builder arrives with 0.8.0.
