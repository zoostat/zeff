# Z0607 — a row with the wrong shape

## Meaning
A row has another number of fields than the header, or opens a quote that is never closed, so the rest of the file was read as one value.

## Common causes
- A delimiter inside a value without quotes: `Smith, John`.
- A quotation mark inside a quoted value not doubled.

## Example
```
> import("data/f.csv")
error[Z0607]: row 3 of `data/f.csv` has 1 field, but the header has 2
```

## Fix
Quote values that hold the delimiter, double a quotation mark inside a quoted value, or fix the row.
