# Z0317 — a pragma that cannot be applied

## Meaning
`// zeff: allow(CODE) reason` silences one warning on one statement (section 11.1, "Deliberate exceptions"). It stands on its own line above the statement or at the end of the statement's first line, names one warning's code, and says why. A pragma that cannot be read, names a code no warning has, gives no reason, or belongs to no statement is an error: passed over in silence it would leave the warning it was written for.

## Common causes
- The reason left out after the code.
- An error's code (`Z` and four digits): an error has to be put right and cannot be allowed.
- A code mistyped, or two codes in one pragma.
- The pragma at the end of a continuation line, or with no statement below it.

## Example
```
> // zeff: allow(W0203)
> let age = to("varies", Float)
error[Z0317]: the pragma gives no reason
  = help: say after the code why the warning is expected, as in `// zeff: allow(W0203) "varies" coded as NA by design`
```

## Fix
Write the pragma on its own line above the statement, or at the end of the statement's first line, with the warning's code and a reason; use one pragma line for each code.
