# Z0320 — help text for a parameter the function does not have

## Meaning
In the `///` text above a `fn`, a line `name: text` documents the parameter `name` (section 5.3, "Help"; section 9.1 of the Engine and Project Specification). A line that names something that is not a parameter, nor one of the page's own keys (`returns:`, `details:`, `reference:`), is this error, so the help can never describe an argument the function lacks.

## Common causes
- A parameter renamed in the signature but not in the text.
- A misspelt parameter name.

## Example
```
> /// Share of rows where a variable is missing.
> /// data: The frame to check.
> /// variable: The variable whose missing values are counted.
> fn share_missing(data: Frame, var: Var) -> Float { ... }
error[Z0320]: the help of `share_missing` describes `variable`, which is not one of its parameters
  = help: did you mean `var:`?
```

## Fix
Name the parameter as the signature does, or start a prose line that needs a colon with a capital letter.
