# W0401 — an option that changes nothing in this call

## Meaning
An option was written out where it has no effect: `level:` of `posthoc` with a step-wise method (`holm`, `hochberg`, `hommel`, `bh`, `by`). Those methods adjust each p-value by its place among the others and have no intervals to match, so there is nothing for a confidence level to set. The result is what it would be without the option; the note is there because the script asks for something it does not get.

## Common causes
- A level kept from a call with `method: tukey` after the method was changed to `holm`.
- Expecting intervals beside step-wise p-values, as some programs print Bonferroni's there.

## Example
```
> d.anova(gain, group: diet).posthoc(method: holm, level: 0.99)
note[W0401]: `level:` changes nothing here: Holm adjusts the p-values step by step and has no intervals (line 1)
  = help: the methods with intervals at the level asked are tukey, scheffe, bonferroni, sidak and none
```

## Fix
Leave `level:` out, or choose a method that has intervals: `tukey`, `scheffe`, `bonferroni`, `sidak` or `none`. `// zeff: allow(W0401) reason` on the statement keeps the option deliberately.
