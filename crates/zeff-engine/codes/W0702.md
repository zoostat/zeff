# W0702 — date-and-time values were converted to UTC

## Meaning
A column of dates with times carried a time-zone offset, such as `+02:00`. Zeff stores every instant in UTC and says how many values it converted, so that the shift is never silent.

## Common causes
- A timestamp export from a system that writes local time with its offset.

## Example
```
> let e = import("data/events.csv")
warning: 2 values of at carried a time-zone offset and were converted to UTC (line 1)
```

## Fix
Nothing, if UTC is what you want; the `time` package (release 0.3.0) brings `to_timezone` for printing in a local zone.
