# W0102 — a name is both a variable of the frame and a binding

## Meaning
Inside a frame method's argument, such as the condition of `where`, a bare name is the frame's variable first and a script binding second (section 3.7 of the Language Reference, "Name lookup"). The name written is both: the variable was used, and this warning says so, since the author may have meant the binding.

## Common causes
- A binding named like a column: `let hours = 40` and then `wages.where(hours > 38)`.
- A column added to a file after a script that used the name for a binding was written.

## Example
```
> let hours = 40
> wages.where(hours > 38)
warning: `hours` is both a variable of wages and a binding; the variable was used (line 2)
```

## Fix
Rename the binding, or, where the binding is meant, write it outside the method: `let limit = hours` and then `wages.where(hours > limit)`.
