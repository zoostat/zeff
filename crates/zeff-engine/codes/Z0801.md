# Z0801 — no row remains to fit the model

## Meaning
Every row of the frame has `NA` in at least one model variable (the outcome, a regressor, a weight or a cluster), so after the rows with `NA` are dropped (section 4.1 of the Language Reference) nothing is left to estimate.

## Common causes
- A variable that is entirely missing in the file, read as `NA` throughout.
- Two variables whose missing rows together cover every row.

## Example
```
> let d = frame(y = [NA, NA], x = [1, 2])
> d.reg(y ~ x)
error[Z0801]: no row remains to fit the model: every row has NA in a model variable
```

## Fix
`describe` shows each variable's missing count; `where(!is_missing(x))` keeps the rows with a value, and `recode(x, [NA => 0])` fills the gaps when a value is right.
