# Z0319 — a module function without its complete page

## Meaning
A function in the project's `functions/` folder is meant for reuse, so it carries the page of section 9.1 of the Engine and Project Specification in its `///` lines: the summary line first, then a description, `name: text` for each parameter, `returns:` for the value, and at least one example, a line `> statement` followed by what it prints. `zeff check` fails the module while any part is missing; a function in a script needs only the summary line (W0303).

## Common causes
- A helper moved from a script to `functions/` without its page.
- A parameter added to the signature but not to the text.
- No `> ` example, or an example that does not parse.

## Example
```
> /// Share of rows where a variable is missing.
> fn share_missing(data: Frame, var: Var) -> Float { ... }
error[Z0319]: the page of `share_missing` in functions/clean.zeff is incomplete: it lacks `data:` and its meaning, `var:` and its meaning, `returns:` and what the value holds, one example, a line `> statement` with its output under it
```

## Fix
Write the missing lines above the `fn`; the example is checked by the build from release 0.7.0 (`zeff test`) and shown by `zeff help`.
