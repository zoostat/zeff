# Z0715 — no file at the path

## Meaning
`import` named a path inside the project at which there is no file, or a folder, or a file that cannot be read.

## Common causes
- A misspelt file name.
- A data file not yet copied into `data/`.
- A folder named instead of a file.

## Example
```
> import("data/missing.csv")
error[Z0715]: no file `data/missing.csv` in the project
```

## Fix
Put the file in the project and write its path from the project folder.
