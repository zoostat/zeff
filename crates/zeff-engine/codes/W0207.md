# W0207 — a level the fit never saw

## Meaning
`predict` was given new data in which a category variable holds a level that was not among the levels of the fit, so the model has no coefficient for it; the predictions of those rows are `NA`. The other rows are predicted as usual.

## Common causes
- New data from another period or source with a category that has gained a level.
- A label spelt differently from the fit's (`retail` for `Retail`).
- A text variable in the new data whose values are not the fit's labels.

## Example
```
> m.predict(newdata: frame(educ = [12, 16], industry = ["Retail", "Space"]))
warning: 1 row of newdata holds a level of `industry` the fit never saw, so its prediction is NA
  = help: the fit's levels of `industry` are "Agriculture", "Mining", "Utilities", "Construction", …
```

## Fix
Recode the new level to one the fit knows, or refit the model on data that holds it.
