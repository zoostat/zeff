# Z0608 — a file that is not UTF-8

## Meaning
The CSV file holds bytes that are not valid UTF-8, named by row. Zeff reads UTF-8 only in this release.

## Common causes
- A file saved in Latin-1 or Windows-1252, often with accented letters.

## Example
```
> import("data/f.csv")
error[Z0608]: row 3 of `data/f.csv` is not valid UTF-8
```

## Fix
Save the file as UTF-8 from the program that made it; `encoding:` for other encodings arrives with 0.2.0.
