# Z0214 — values that should share one type do not

## Meaning
A list holds one type of value, Int and Float joining as Float, and `NA` fitting any; a mapping has one key type and one value type; the two branches of an `if` used as a value, and the arms of a `case`, give one type between them (section 3.7, "Joining types").

## Common causes
- Text and numbers in one list: `[1, "a"]`.
- A mapping with Int keys and one text key.
- An `if` whose `else` branch gives text where the first gives a number, or an `if` whose one branch ends in a `let` and gives no value.
- A `case` whose arms mix a number and text, or give a Category column beside text.

## Example
```
> [1, "a"]
error[Z0214]: a list holds one type: this one has an Int and a Str
```

## Fix
Put values of one type in the list, or end every branch and arm with the same type; convert with `to` where a mixture is meant to be text.
