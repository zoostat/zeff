# Z0214 — a list or mapping holds values of more than one type

## Meaning
A list holds one type of value, Int and Float joining as Float, and `NA` fitting any; a mapping has one key type and one value type.

## Common causes
- Text and numbers in one list: `[1, "a"]`.
- A mapping with Int keys and one text key.

## Example
```
> [1, "a"]
error[Z0214]: a list holds one type: this one has an Int and a Str
```

## Fix
Put values of one type in the list; convert with `to` where a mixture is meant to be text.
