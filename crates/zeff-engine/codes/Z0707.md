# Z0707 — a file cannot be written

## Meaning
The engine could not create or write a file or folder, usually when `zeff new` makes a project.

## Common causes
- A folder that already exists.
- No permission to write in the current folder.

## Example
```
> zeff new schooling
error[Z0707]: cannot write `schooling`: the folder already exists
```

## Fix
Choose another name or folder, or remove what is in the way.
