# Z0221 — an operator applied to types it does not take

## Meaning
An operator was given values of types it does not work on: a Bool in arithmetic, `!` on a number, `&&` on numbers, a comparison across types, a date added to a number, a list indexed by text, a mapping looked up by a key of another type.

## Common causes
- `true + 1`: Bool is not a number in Zeff.
- `1 == "1"`: a number and text.
- `d + 7` on a date: a date moves with `add_days(d, 7)` or `add_months(d, 1)`; `Date - Date` gives the days between two dates, and two DateTimes are compared with `days_between`.
- `xs["a"]` on a list.

## Example
```
> true + 1
error[Z0221]: `+` needs numbers, but one side is a Bool
  = help: Bool is not a number; `to(x, Int)` turns true and false into 1 and 0
```

## Fix
Convert first with `to`, or compare values of one type.
