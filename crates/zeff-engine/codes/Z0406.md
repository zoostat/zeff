# Z0406 — a required argument is missing

## Meaning
The function needs an argument that was not given: the frame, a variable, or at least one definition.

## Common causes
- `mean()` without a frame.
- `frame()` with no column defined.

## Example
```
> wages.mean()
error[Z0406]: `mean` needs `var`
  = help: usage: `data.mean(var)`
```

## Fix
Give the argument the usage line names.
