# W0302 — a `let` that shadows a loop variable

## Meaning
A `let` inside a loop body reuses the name of the loop variable (or, from release 0.5.0's functions, of a parameter). The new binding hides the loop variable until the block ends, which is allowed but hard to read, so the checker says so once.

## Common causes
- `for i in 1..10 { let i = i * 2 ... }`, meant as a transformation of the loop variable.
- A name chosen for the body without looking at the loop's header.

## Example
```
> for i in 1..3 {
>     let i = i * 2
>     print(i)
> }
warning[W0302]: `i` shadows the loop variable of the same name
  = help: the loop variable is hidden until the block ends; a different name keeps both readable
```

## Fix
Give the inner binding a name of its own, `let doubled = i * 2`.
