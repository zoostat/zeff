# Z0223 — an infinite value in a model variable

## Meaning
A model variable, the outcome, a regressor, a weight or a cluster, holds `Inf` or `-Inf` in some rows, and a model cannot use an infinite value (section 4.1 of the Language Reference: rows with `NA` are dropped and counted, but an infinity is an error listing the rows). A transformation can produce one too: `log(x)` of a zero, or a division by zero.

## Common causes
- A file read with `Inf` in a numeric column.
- `log(x)` with zeros in `x`, or `a / b` with zeros in `b`, written as a term.

## Example
```
> let m = wages.reg(wage ~ log(hours))
error[Z0223]: `log(hours)` holds an infinite value in rows 12, 84 and 2 more
```

## Fix
Drop the rows, `where(x != Inf && x != -Inf)`, recode the values, or transform differently (`log(x + 1)`).
