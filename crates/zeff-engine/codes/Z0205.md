# Z0205 — a function passed where one of another signature is needed

## Meaning
A parameter typed `Fn(T1, T2) -> R` takes a named function whose parameter types and return type match exactly, defaults ignored (section 3.7, "Functions as values"). The message shows the signature of the function given and the signature needed.

## Common causes
- A function that gives a Float where one giving an Int is needed: `sqrt` on an Int gives a Float.
- A function of the script written for one type and passed where another is named.
- A step function for `iterate` that returns something other than a record.

A built-in function is read at the argument types the parameter names: `abs`, which takes an Int or a Float and gives a number of the same kind, is `Fn(Int) -> Int` where that is wanted and `Fn(Float) -> Float` where that is.

## Example
```
> /// Applies a function to an integer.
> fn apply(f: Fn(Int) -> Int, x: Int) -> Int { f(x) }
> apply(sqrt, 4)
error[Z0205]: `sqrt` has the signature `Fn(Int) -> Float`, but `Fn(Int) -> Int` is needed here
  = help: a function passed as a value matches the parameter types and the return type exactly, defaults ignored; write a function with that signature
```

## Fix
Write a function with the signature the parameter names, or change the parameter's type.
