# Z0609 — a column of two types across an append

## Meaning
`append` stacks the rows of one frame below another's, matching columns by name, and the rows of one column have one type. An Int column beside a Float one becomes Float, and a category's levels are joined; a column of any other pair of types, text below numbers, a date below text, is refused and named.

## Common causes
- A year read as text in one file and as a number in another.
- A code column that one file labels as a category and another leaves as numbers.
- Two files whose columns of the same name mean different things.

## Example
```
> let a = frame(id = [1, 2], year = [2010, 2011])
> let b = frame(id = [3], year = ["2012"])
> a.append(b)
error[Z0609]: `year` is a column of Int in a and of Str in b
 --> scripts/main.zeff:3:10
  |
3 | a.append(b)
  |          ^ a column of another type
  |
  = help: the rows of one column have one type; convert one side first with `to`, or `drop` the column from one frame
```

## Fix
Convert one side, `b.add(year = to(year, Int))`, or `rename` or `drop` the column on one side before appending.
