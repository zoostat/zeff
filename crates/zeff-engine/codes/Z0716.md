# Z0716 — a path names no format, or a format not yet written

## Meaning
`export` and `save` choose a file's format from the path's extension, or from `format:` for `save`. The path given has no extension, or one the function does not write: `export` writes a table as `.docx` (Word) or `.tex` (LaTeX); `save` writes a frame as `.csv` or `.tsv` at this release, and names the release that brings Parquet, Arrow, Stata, Excel and JSON (0.11.0) or SPSS (1.1) when one of those is asked for.

## Common causes
- A path without an extension: `save("output/table")`.
- A format of a later release: `save("output/wages.parquet")`.
- A file name with a dot and nothing after it.

## Example
```
> let by_year = frame(year = [2010, 2011], sales = [120.5, 130])
> by_year.save("output/by_year.parquet")
error[Z0716]: `save` writes Parquet files from release 0.11.0; this release writes CSV and TSV
 --> scripts/main.zeff:2:14
  |
2 | by_year.save("output/by_year.parquet")
  |              ^^^^^^^^^^^^^^^^^^^^^^^^ Parquet arrives with release 0.11.0
  |
  = help: write `.csv` or `.tsv` for now; Parquet, Arrow, Stata, Excel and JSON come with the reader interface of 0.11.0
```

## Fix
Give the path the extension of a format the function writes, or `format:` for `save`.
