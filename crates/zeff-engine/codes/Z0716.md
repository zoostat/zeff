# Z0716 — an export path names no format

## Meaning
`export` chooses the file's format from the path's extension, and the path given has none, or one Zeff does not write. A table is written as `.docx` (Word) or `.tex` (LaTeX); plots, when they arrive, as `.svg`, `.pdf` or `.png`.

## Common causes
- A path without an extension: `export("output/table1")`.
- An extension of another program: `.xlsx`, `.csv`, `.html`.
- The extension of a plot format given to a table.

## Example
```
> wages.describe().export("output/table1.xlsx")
error[Z0716]: `output/table1.xlsx` has an extension Zeff does not write
  = help: a table is written as `.docx` (Word) or `.tex` (LaTeX): `output/table1.docx`
```

## Fix
Write the extension of the format wanted; `save` writes data files such as CSV.
