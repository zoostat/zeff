# Z0706 — an edition this engine does not know

## Meaning
`zeff.toml` names an edition the engine cannot run: either not the `preview` edition of these releases, or an edition of a later engine.

## Common causes
- `edition = "2027"` before 1.0.
- A typo in the edition.

## Example
```
> zeff run
error[Z0706]: this engine does not know the edition `2027`
```

## Fix
Write `edition = "preview"` for this release.
