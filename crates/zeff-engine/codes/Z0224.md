# Z0224 — a negative weight

## Meaning
A weight variable holds a value below zero in some rows. A weight is a count, a precision or a probability of selection (section 6 of the Language Reference), none of which can be negative, so the model stops and lists the rows (section 4.1, "Weights"); a zero weight leaves its row out with a note, and `NA` drops it with the others.

## Common causes
- A weight computed with the wrong sign, or a variable that is not a weight.
- A code such as `-1` used for a missing weight.

## Example
```
> wages.reg(wage ~ educ, weights: w)
error[Z0224]: `w` holds a negative weight in rows 3, 17
```

## Fix
Recode the negative values, or drop their rows: `where(w >= 0)`.
