# W0301 — a `case` arm that can never be reached

## Meaning
The arms of a `case` are checked in order and the first true one wins. An arm whose condition is always true takes every row, so the arms written after it can never be reached. The script runs; the later arms are dead.

## Common causes
- `true => value` written as the catch-all in the middle of a `case`; the catch-all is `_` and belongs last.
- An arm left in place after the one before it was widened.

## Example
```
> let band = case { true => "all", wage < 15 => "low" }
warning[W0301]: this condition is always true, so the arms after it can never be reached
  = help: write the catch-all as the last arm, `_ => value`, or remove the arms after this one
```

## Fix
Move the always-true arm last and write it as `_`, or remove the arms after it.
