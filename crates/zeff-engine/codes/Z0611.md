# Z0611 — two rows for one cell of to_wide

## Meaning
`to_wide(values_from:, id:, names_from:)` gives one row per id and one column per name, and each cell holds the value of the one row with that id and name. Two rows with the same id and name cannot share a cell, so the call is refused and the pair named. Two names that print alike, so that two new columns would have one name, are refused the same way.

## Common causes
- An id that does not identify a row alone: a firm observed twice in one year, in two regions.
- A long frame appended to itself.
- Names that differ only beyond what their printed form shows.

## Example
```
> let long = frame(firm = [1, 1, 1], year = [2010, 2010, 2011], sales = [120, 125, 130])
> long.to_wide(values_from: sales, id: firm, names_from: year)
error[Z0611]: `firm` 1 appears twice at `year` 2010
 --> scripts/main.zeff:2:38
  |
2 | long.to_wide(values_from: sales, id: firm, names_from: year)
  |                                      ^^^^ an id with two rows for one name
  |
  = help: `duplicates([firm, year])` lists the repeated pairs; `aggregate` them or add the variable that tells them apart to `id:`
```

## Fix
`duplicates([id, names_from])` shows the pairs; `aggregate` the rows to one per pair, or add the variable that tells them apart to `id:`.
