# Z0606 — a value that does not fit its column's type

## Meaning
A CSV column's type is guessed from its first 1,000 rows, or declared with `types:`; a later value that does not fit, such as text in a numeric column, stops the import. Zeff never turns it into `NA` silently.

## Common causes
- A code such as `varies` or `n/a` after a thousand numbers.
- A decimal in a column guessed as whole numbers.
- A declared `Bool` with values other than true and false.

## Example
```
> import("data/long.csv")
error[Z0606]: row 1,002 of `data/long.csv` has text in a numeric column
  = help: declare it with `types: {hours: Str}`, add "varies" to `na_values:`, or fix the file
```

## Fix
Declare the column's type, add the code to `na_values:`, or fix the file.
