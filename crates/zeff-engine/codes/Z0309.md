# Z0309 — a declaration in the wrong place

## Meaning
`use` must come before the first statement, and `fn` and `use` appear only at the top level of a file.

## Common causes
- A `use` written after some statements.
- A function defined inside another.

## Example
```
> print(1)
> use clean
error[Z0309]: `use` must come before the first statement
```

## Fix
Move the declaration to the top of the file.
