# Z0709 — not inside a project

## Meaning
`zeff run`, `zeff check`, `zeff test` and `zeff fmt` need a project: a folder with `zeff.toml` in it or above it.

## Common causes
- A script run from a folder that is not a project.
- A project folder whose `zeff.toml` was deleted.

## Example
```
> zeff run
error[Z0709]: not inside a Zeff project; `zeff new <name>` creates one
```

## Fix
Change into the project's folder, or create one with `zeff new <name>`.
