# Z0408 — a positional argument after a named one

## Meaning
Once an argument is named, the rest must be named too.

## Common causes
- `import(header: false, "data/x.csv")`.

## Example
```
> import(header: false, "d.csv")
error[Z0408]: a positional argument after a named one
```

## Fix
Put the positional arguments first, or name every argument.
