# W0208 — rows of a `case` that no arm matched

## Meaning
A `case` without a catch-all `_` left some rows, or the one value, unmatched: no arm's condition was true there (a condition that is `NA` does not match), so the result is `NA` in those rows. The warning counts them.

## Common causes
- Bands that do not cover the whole range: `case { age < 25 => "young", age < 55 => "prime" }` leaves ages of 55 and over.
- A variable with `NA`, whose rows match no comparison.
- A `case` over one value whose conditions are all false.

## Example
```
> wages.add(age_group = case { age < 25 => "young", age < 55 => "prime" })
warning: 3,112 rows matched no arm of the `case` and are NA (line 4)
  = help: add a last arm for the rest, `_ => value`
```

## Fix
Add a last arm, `_ => value`, for the rest; or, if `NA` is meant, write it as `_ => NA` so that the intent is on the page.
