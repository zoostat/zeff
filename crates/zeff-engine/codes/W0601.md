# W0601 — text values differ only in their Unicode normalisation form

## Meaning
A text column holds two spellings of the same letters that differ only in how an accent is composed (`é` as one character or as `e` plus an accent). Zeff treats them as different values, so `==` and grouping would keep them apart.

## Common causes
- A file assembled from sources that normalise text differently (a Mac and a Windows export, a web form and a spreadsheet).

## Example
```
> let d = import("data/cities.csv")
warning: city holds values that differ only in their Unicode normalisation form, such as "café" and "café" (line 1)
```

## Fix
Normalise the text in the file (most editors and spreadsheets save NFC), so that the two spellings become one value.
