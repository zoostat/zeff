# Z0407 — too many arguments

## Meaning
More positional arguments were given than the function takes.

## Common causes
- Two variables to a function of one: `wages.mean(wage, hours)`.

## Example
```
> wages.mean(wage, hours)
error[Z0407]: `mean` takes 1 argument, but more were given
```

## Fix
Give one call per variable, or use `summary` for several.
