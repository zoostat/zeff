# W1003 — extreme weights

## Meaning
The weights are so uneven that a few rows carry most of the weight: Kish's effective sample size, (Σw)² / Σw², is below a quarter of the rows used. The estimates then rest on those few rows, and the standard errors are larger than the row count suggests (section 11.1 of the Language Reference).

## Common causes
- Sampling weights with a long tail: a few units standing for a large part of the population.
- A weight variable that is not a weight: an income, a size.

## Example
```
> wages.reg(log(wage) ~ educ, weights: w)
warning: extreme weights: the effective sample size is 1,204 of 18,184 rows
```

## Fix
Check the rows with the largest weights; trim or winsorise the weights if the design allows it.
