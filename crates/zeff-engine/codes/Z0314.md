# Z0314 — operators that do not chain

## Meaning
Comparisons, ranges and formula operators take two sides and do not chain: `a < b < c`, `1..2..3` and `y ~ x ~ z` are errors.

## Common causes
- A mathematical inequality `0 < x < 1` written as such.

## Example
```
> 0 < x < 1
error[Z0314]: comparisons do not chain
```

## Fix
Write `0 < x && x < 1`.
