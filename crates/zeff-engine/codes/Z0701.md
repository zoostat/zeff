# Z0701 — a path outside the project

## Meaning
Projects read only their own files and the data roots declared in `zeff.toml`; a path with `..`, an absolute path, or an empty path is refused.

## Common causes
- `import("../shared/wages.csv")`.
- A full path pasted from a file browser.

## Example
```
> import("../shared/wages.csv")
error[Z0701]: path `../shared/wages.csv` is outside the project
```

## Fix
Declare the folder under `[data]` in `zeff.toml` and write `import("shared:wages.csv")`, or copy the file into `data/`.
