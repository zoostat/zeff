# Z0714 — no such script in the project

## Meaning
The script named on the command line is not a file of the project.

## Common causes
- A misspelt script path.
- A script in another project.

## Example
```
> zeff check scripts/other.zeff
error[Z0714]: no script `scripts/other.zeff` in the project
```

## Fix
Write the script's path from the project folder, as in `scripts/clean.zeff`.
