# Z0316 — the catch-all of a `case` out of place

## Meaning
`_` catches every row no earlier arm matched, so it may appear once in a `case`, and only as the last arm; an arm written after it could never be reached.

## Common causes
- `_` written first, in the manner of a default that later arms refine.
- Two `_` arms.

## Example
```
> case { _ => "other", age < 25 => "young" }
error[Z0316]: `_` may appear once in a `case`, and only as the last arm
  = help: put the `_` arm last
```

## Fix
Put the `_` arm last and keep one.
