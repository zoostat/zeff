# Z0316 — a statement that is not one

## Meaning
The parser found something where a statement should begin that cannot start one, or a statement left unfinished.

## Common causes
- A `let` without a value.
- Text left over from an edit.

## Example
```
> let x =
error[Z0316]: expected a value after `=`
```

## Fix
Complete or remove the statement.
