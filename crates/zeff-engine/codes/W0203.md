# W0203 — a value could not be converted and became NA

## Meaning
`to` converts by the table of section 3.7 of the Language Reference; a value that does not read as the target type becomes `NA`, and this warning gives the count and up to three of the failing values. Nothing is converted by guesswork.

## Common causes
- `to("1,000", Float)`: grouped digits need `thousands:` at import.
- `to("yes", Bool)`: only `true` and `false`, in any case, convert.
- `to(7, Bool)`: only 0 and 1 convert.

## Example
```
> to("1,000", Float)
NA
warning: "1,000" could not be converted to Float and became NA
  = help: the page of `to` lists what converts; `is_missing` finds the NA afterwards
```

## Fix
Clean the values first, or find the rows that became `NA` with `is_missing`.
