# Z0218 — a column given to a parameter that takes one value

## Meaning
A built-in function of one value, such as `log`, applies row by row when given a column. A function defined in the script is not lifted that way: its parameter types are taken literally (section 3.7, "Columns and scalars"), so `fn double(x: Float)` takes one Float and refuses a column.

## Common causes
- `wages.add(w2 = double(wage))` with `fn double(x: Float)`.
- A function written for one value and used on a variable.

## Example
```
> fn double(x: Float) -> Float { x * 2 }
> wages.add(w2 = double(wage))
error[Z0218]: `x` of `double` takes one value, a Float, but this is a Column
  = help: declare `x: Column<Float>`, or write the expression inside `add`; a project function is not applied row by row
```

## Fix
Declare the parameter as a column, `x: Column<Float>`, when the function works on variables; or write the expression inside `add` directly.
