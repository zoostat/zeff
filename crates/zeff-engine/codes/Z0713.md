# Z0713 — zeff.toml is wrong for Zeff

## Meaning
The project file is valid TOML but not a Zeff project file: a key is unknown or misspelt, `name`, `zeff` or `edition` is missing, a value has the wrong kind, the pin is not one exact version, or a data root has no `path`.

## Common causes
- `netwrk` for `network`: a misspelt setting is an error, never ignored.
- A pin written as a range.

## Example
```
> zeff run
error[Z0713]: `zeff.toml` has an unknown key `netwrk`
```

## Fix
Correct the key or value; `zeff new` writes the three required keys.
