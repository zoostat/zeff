# Z0103 — no such function

## Meaning
A call names a function that no package of this engine has, with a suggestion when a close name exists.

## Common causes
- A misspelt function: `wages.maen(wage)`.
- A function of a later release, which says when it arrives.
- An R or Stata name that Zeff spells differently.

## Example
```
> wages.maen(wage)
error[Z0103]: no function is called `maen`
  = help: did you mean `mean`?
```

## Fix
Correct the spelling; `zeff help data` lists a package's functions and `zeff help <name>` says when a later one arrives.
