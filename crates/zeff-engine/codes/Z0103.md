# Z0103 — no such function

## Meaning
A call names a function that no package of this engine has. The help says what is known of the name: a close name, where one exists; the release and the package, where the catalogue has the function for a later release; or the Zeff form of a term that R writes with a function inside a formula.

## Common causes
- A misspelt function: `wages.maen(wage)`.
- A function of a later release, which says when it arrives.
- An R or Stata name that Zeff spells differently.
- `I(...)` or `poly(...)` inside a formula. Zeff works out the arithmetic of a formula before fitting, so a power stands as it is, `exper^2`, and a polynomial is its powers written out, `exper + exper^2`. In a model with an intercept these give the fitted values of R's `poly`; the coefficients are those R gives with `raw = TRUE`.

## Example
```
> wages.maen(wage)
error[Z0103]: no function is called `maen`
  = help: did you mean `mean`?

> wages.reg(log(wage) ~ educ + exper + I(exper^2))
error[Z0103]: no function is called `I`
  = help: arithmetic in a formula is worked out before fitting, so `I()` is not needed: write `exper^2`

> wages.did(wage, treat: union)
error[Z0103]: no function is called `did`
  = help: `did` arrives with a release after 1.0, in the `quasi` package; `zeff help did` says what it will do
```

## Fix
Correct the spelling; `zeff help data` lists a package's functions and `zeff help <name>` says when a later one arrives. Inside a formula write the term as the help shows it. A name of one letter is offered no near name, since every short name is near it; the same letter in the other case is still offered.
