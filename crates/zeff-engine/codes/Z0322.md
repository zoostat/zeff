# Z0322 — a one-sided formula where none is taken

## Meaning
A formula without an outcome, `~ x`, is allowed only where a parameter takes a one-sided formula, such as `zero:` in later releases. No function of this release takes one, so a `~` needs an outcome on its left.

## Common causes
- The outcome forgotten: `~ educ + exper` for `lwage ~ educ + exper`.
- A line break before `~`, which leaves the outcome on the line above.

## Example
```
> let f = ~ educ + exper
error[Z0322]: a one-sided formula `~ x` is allowed only where a parameter takes one
```

## Fix
Write the outcome on the left of `~`.
