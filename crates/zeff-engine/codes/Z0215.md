# Z0215 — arithmetic on text

## Meaning
No operator joins or repeats text: `"a" + "b"` is not a way to build text in Zeff.

## Common causes
- Joining two texts with `+`.
- A number that was read as text, multiplied.

## Example
```
> "a" + "b"
error[Z0215]: `+` does not apply to text
```

## Fix
`join` puts texts together and `format` builds text from values (release 0.5.0); a number in text converts with `to(x, Float)`.
