# Z0206 — a statement's result cannot be bound or passed

## Meaning
`print`, `warn` and the other statements that print or warn return `Nothing`, which cannot be given a name or handed to a function.

## Common causes
- `let x = print(1)`.
- `print(print(1))`.
- Using the result of `print` in arithmetic.

## Example
```
> let x = print(1)
error[Z0206]: this gives no value, so it cannot be bound
```

## Fix
Bind or pass the value itself; print it in its own statement.
