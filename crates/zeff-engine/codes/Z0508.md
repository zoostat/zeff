# Z0508 — a `dag { }` block that is no graph of causes

## Meaning
A `dag { }` block states which variable acts on which. Three things cannot be such a statement, and each stops the script when it is checked, before anything runs. A directed cycle: following the arrows from a variable leads back to it, so that it would be a cause of itself; the message names the cycle from its first node round to it again. An edge from a node to itself. A node declared both `latent` and `selected`: a latent variable is not observed, and data cannot be selected on what is not observed.

## Common causes
- Two variables that act on each other written as arrows both ways, `price -> demand` and `demand -> price`.
- A long chain whose last arrow points back to a variable near its start.
- The same name used for a variable at two times.
- A name repeated in a group, `[a, b] -> a`.

## Example
```
> let market = dag {
>     price -> demand
>     demand -> price
> }
error[Z0508]: the `dag { }` block has a directed cycle: price -> demand -> price
  = help: a causal graph has no cycle: a variable cannot be a cause of itself. For two variables that move together write `a <-> b`; for feedback over time write one variable for each period
```

## Fix
For two variables that move together because of something not in the graph, write `price <-> demand`. For feedback over time, write a node for each period, `price_1 -> demand_2`, so that every arrow goes forward. For a variable declared twice, keep the declaration that is true of it.
