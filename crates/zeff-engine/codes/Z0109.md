# Z0109 — a name both built in and defined in the script

## Meaning
The script defines a function with the name of a built-in one, and a bare call could mean either. Zeff never chooses in silence (section 3.6, "Built-in names"): both are written in full, `functions::summary(...)` for the script's and `data::summary(...)` for the built-in.

## Common causes
- A helper named like a built-in function, `mean`, `summary`, `describe`.
- A function written before a later release added a built-in of the same name; `zeff engine use` lists such calls before the pin moves.

## Example
```
> fn summary(data: Frame) -> Table { data.describe() }
> wages.summary()
error[Z0109]: `summary` is both a built-in function and a function of this script
  = help: write it in full: `functions::summary(...)` for the script's, `data::summary(...)` for the built-in
```

## Fix
Write the call in full, or rename the script's function.
