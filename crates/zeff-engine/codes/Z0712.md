# Z0712 — zeff.toml is not valid TOML

## Meaning
The project file cannot be read as TOML: a bracket, quote or `=` is wrong.

## Common causes
- `[project` without its closing bracket.
- A value without quotes.

## Example
```
> zeff run
error[Z0712]: zeff.toml is not valid TOML
```

## Fix
Fix the line the message points at; `zeff new` writes a valid file to compare with.
