# Z0308 — an operator that belongs in a model block

## Meaning
`as`, `=~`, `~~` and `:=` have meaning only inside `model { }`; outside it they are errors.

## Common causes
- A lavaan-style line written outside a model block.

## Example
```
> dem60 =~ y1 + y2
error[Z0308]: `=~` is only allowed inside a `model { }` block
```

## Fix
Put the line inside `model { }` (release 1.3), or use the formula operator `~`.
