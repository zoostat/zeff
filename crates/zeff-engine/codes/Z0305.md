# Z0305 — a line begins with an operator

## Meaning
A statement cannot begin with `-`, `+`, `*`, `/` or another operator: a line break ends a statement, so an operator at the start of a line has nothing on its left.

## Common causes
- A long expression continued on the next line with the operator first.
- `-7` on a line of its own.

## Example
```
> -7
error[Z0305]: this line begins with an operator
  = help: did you mean to continue the previous line? End that line with the operator
```

## Fix
End the previous line with the operator, or write `print(-7)` or `let x = -7`.
