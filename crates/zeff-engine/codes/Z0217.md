# Z0217 — columns or lists of different lengths

## Meaning
Two columns combine only when they have the same number of rows, and `frame` builds a frame from lists of one length.

## Common causes
- Columns taken from two frames with different rows.
- Lists of different lengths given to `frame`.

## Example
```
> frame(a = [1, 2], b = [1, 2, 3])
error[Z0217]: `frame` needs lists of one length: `a` has 2 values and `b` has 3
```

## Fix
Give every column the same number of values, writing `NA` for a missing one; to combine frames, `merge` (release 0.6.0).
