# Z0419 — a regular expression that cannot be read

## Meaning
A pattern given with `regex: true` to `contains` or `replace`, or to `extract` or `split`, is not a regular expression of section 3.8 of the Language Reference: a bracket or parenthesis is not closed, a repetition has nothing to repeat, or the pattern uses look-around or a back-reference, which Zeff's regular expressions do not have, so that every match runs in linear time and reads the same on every machine.

## Common causes
- An unbalanced `(` or `[`, as in `"(ab"`.
- A `*`, `+` or `?` at the start of the pattern.
- `(?=...)`, `(?!...)`, `(?<=...)` or `\1`, which other engines accept.

## Example
```
> contains("abc", "(ab", regex: true)
error[Z0419]: `(ab` is not a regular expression: the group is not closed
  = help: the syntax is Rust's `regex` crate's: Unicode classes, no back-references or look-around (section 3.8)
```

## Fix
Close the group or bracket, or write the pattern without look-around; for a literal text, leave `regex:` off, and `contains` looks for the text itself.
