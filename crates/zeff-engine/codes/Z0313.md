# Z0313 — a word used outside its place

## Meaning
`return` belongs in a function, `break` and `continue` in a loop, `_` in a `case`; written elsewhere they are errors.

## Common causes
- `return` at the top level of a script.

## Example
```
> return 1
error[Z0313]: `return` is only allowed inside a function
```

## Fix
Move the word into its place, or remove it.
