# Z0323 — a module file that is not one

## Meaning
A module is one file of the project's `functions/` folder (section 5.3, "Modules"). It holds `///` text, `fn` definitions and `use` lines only, and its name, the file's stem, is a name of the language (snake_case) that is not a package's, since `use functions::clean` and `clean::share_missing` name it.

## Common causes
- A statement in a module file: a `let`, an `import`, a call written to try the function.
- A file named with a space or a hyphen, `clean wages.zeff`.
- A module named like a package, `data.zeff` or `core.zeff`.

## Example
```
> let wages = import("data/wages.csv")      // in functions/clean.zeff
error[Z0323]: a module file holds `///` text, `fn` definitions and `use` lines only
  = help: move the statement to a script in `scripts/`; a module's functions take what they need as arguments
```

## Fix
Move statements to a script in `scripts/`, and name module files in snake_case with names of their own.
