# Z0804 — an under-identified model

## Meaning
An instrumental-variables model needs at least as many excluded instruments as it has instrumented regressors (the order condition; section 7.1). `instruments:` gives fewer, so the coefficients of the instrumented regressors cannot be told apart and nothing can be estimated. An instrument that is also a regressor of the formula is an included instrument and does not count: it is in the model already and identifies nothing.

## Common causes
- Two regressors instrumented by one variable.
- An instrument that is also written in the formula, so that it is included and not excluded.
- A range of instruments, `z1..z3`, that names fewer variables than expected once it meets the frame; such a range is counted when the statement runs.

## Example
```
> card.ivreg(lwage ~ exper + educ, instruments: educ + exper ~ nearc4)
error[Z0804]: the model is under-identified: 1 excluded instrument for 2 instrumented regressors
  = help: each instrumented regressor needs at least one instrument that is not a regressor of the formula
```

## Fix
Give an excluded instrument for each instrumented regressor, `instruments: educ + exper ~ nearc4 + age2`, or instrument fewer regressors. With exactly as many instruments as instrumented regressors the model is just identified; with more it is over-identified and `first_stage` reports the test of the extra ones.
