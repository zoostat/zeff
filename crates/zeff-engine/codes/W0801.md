# W0801 — failed values skipped

## Meaning
A collecting function (`report`, and `len` from release 0.5.0) was given a list in which some values are `Failed`, from `attempt` in a loop. The failed values are left out and counted; the warning names how many failed, with the first failures' codes and lines, so that a failure in repeated work is never silent and never throws the rest away (section 5.4).

## Common causes
- A simulation whose fits sometimes cannot be estimated: no row left after a filter, no variation in the outcome, a singular design.
- Subsamples that are too small for the model.

## Example
```
> let fits = [for cut in [10, 20, 1000] {
>     attempt(w.where(wage > cut).reg(log(wage) ~ educ))
> }]
> report(fits)
warning: 1 of 3 fits failed (Z0801 at line 2) and was skipped (line 4)
  = help: the table uses the fits that succeeded; `x.is(Failed)` tells which failed
```

## Fix
Nothing, if a few failures are expected; otherwise look at the first failure's code and line and fix what it names.
