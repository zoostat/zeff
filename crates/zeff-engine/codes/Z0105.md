# Z0105 — a name of core cannot be rebound

## Meaning
A `let` tried to take a name that belongs to `core`: a built-in function such as `print`, a type name such as `Str` or `Frame`, or a name reserved for a later value such as `Matrix`. Those names are fixed so that every script reads the same.

## Common causes
- `let print = ...`, `let Str = ...`, `let matrix = ...`.

## Example
```
> let print = 1
error[Z0105]: `print` is a name of `core` and cannot be rebound
```

## Fix
Choose another name.
