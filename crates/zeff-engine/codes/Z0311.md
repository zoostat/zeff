# Z0311 — a string is never closed or has an unknown escape

## Meaning
A string ends at a closing quote on the same line; one that runs to the end of the line is unclosed. The escapes are `\n`, `\t`, `\r`, `\"`, `\\` and `\u{...}`; any other backslash is an error.

## Common causes
- A missing closing quote.
- A Windows path with backslashes written in an ordinary string.

## Example
```
> print("hello)
error[Z0311]: this string is never closed
```

## Fix
Close the string; for paths and regular expressions use a raw string, `r"D:\surveys"`.
