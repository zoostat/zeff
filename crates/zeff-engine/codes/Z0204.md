# Z0204 — no such key in a mapping

## Meaning
A mapping was looked up with a key it does not hold: `m[k]` is an error, never `NA`, so a wrong code is noticed.

## Common causes
- A code not listed in the mapping, such as a missing-value code.
- A key of another type that happens to print the same.

## Example
```
> let labels = [0 => "male", 1 => "female"]
> labels[2]
error[Z0204]: no key `2` in the mapping
```

## Fix
Add the entry to the mapping, or test for the key first with `is_in(k, keys(m))` (release 0.5.0).
