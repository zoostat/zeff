# Z0601 — a panel declaration refused

## Meaning
`panel(unit:, time:)` could not declare the frame a panel: a unit was observed twice at one time, a unit or time value is `NA`, or the time variable is not an Int or a `Date`. A panel's lags and leads follow each unit's time order, which such rows would make ambiguous; Stata's `xtset` refuses the same cases ("repeated time values within panel").

## Common causes
- Two rows for one worker in one year, often from a merge that matched twice or a file appended to itself: `duplicates([worker, year])` lists them.
- A missing identifier or period: `where(is_missing(year))` shows the rows.
- A time written as text or as a Float: `to(year, Int)`, or `date(period)` for a calendar day.

## Example
```
> frame(firm = [1, 1], year = [2020, 2020], sales = [8, 9]).panel(unit: firm, time: year)
error[Z0601]: `firm` 1 is observed twice at `year` 2020
  = help: a unit has one row per time: `duplicates([firm, year])` lists the repeated pairs; drop or aggregate them first
```

## Fix
Remove or aggregate the repeated rows, drop the rows with `NA`, or convert the time variable; then declare the panel again.
