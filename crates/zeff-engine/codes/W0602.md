# W0602 — a category with more than 10,000 levels

## Meaning
`category` made a variable with more than 10,000 levels. A category stands for a few groups; so many levels usually mean that an identifier column, a worker or firm number, was categorised by mistake, and every table and model using it would carry thousands of indicators.

## Common causes
- `category(worker)` on a panel's unit identifier.
- `category(wage)` on a measured variable with thousands of distinct values.

## Example
```
> let w = dataset(wages).add(c = category(worker * 100 + year))
warning: the category has 18,412 levels, more than 10,000: an identifier may have been categorised
  = help: a category stands for a few groups; keep an identifier as a number or text
```

## Fix
Keep identifiers as numbers or text; categorise the variable that holds groups, or bin a measured variable first.
