# Z0318 — a documentation line in the wrong place

## Meaning
A `///` line documents the `fn` directly below it; anywhere else it is an error.

## Common causes
- A `///` comment used as an ordinary comment.

## Example
```
> /// a note
> print(1)
error[Z0318]: a `///` line must be directly above a `fn`
```

## Fix
Write an ordinary comment with `//`, or put the line directly above a function.
