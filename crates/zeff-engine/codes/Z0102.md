# Z0102 — a name differs only in case from a variable

## Meaning
The variable written differs from one of the frame's variables only in upper and lower case. Names are case-sensitive, so this is almost always a slip.

## Common causes
- `Wage` for `wage`, often after `names: snake` on import.

## Example
```
> wages.mean(Wage)
error[Z0102]: no variable `Wage` in `wages`; names are case-sensitive
  = help: write `wage`
```

## Fix
Write the name as the frame has it; `wages.variables()` lists them.
