# W1002 — few clusters

## Meaning
Clustered standard errors (CR1) rest on the number of clusters, not the number of rows: with fewer than 30 clusters the sandwich estimate of the variance is itself noisy and the t table on G − 1 degrees of freedom is a rough guide (section 11.1 of the Language Reference). The fit is reported; the warning is printed beside it.

## Common causes
- Clustering by a variable with few values: a dozen industries, a handful of regions.

## Example
```
> wages.reg(log(wage) ~ educ, cluster: industry)
warning: few clusters: 12 clusters give clustered errors little to rest on
```

## Fix
Cluster at a finer level when the dependence allows it; the wild cluster bootstrap (`se: bootstrap`, release 1.1) is the usual remedy below 30 clusters.
