# Z0304 — not available in this release

## Meaning
The grammar has this construct, but this release of the engine does not run it yet; the message says which release brings it. Nothing is wrong with the script.

## Common causes
- A `model { }` block, or a label written with `as` inside one, before release 1.12. These are the checker's remaining refusals: `if`, `case`, `for`, `fn` and `use functions::…` run from 0.5.0, and a `dag { }` block from 0.10.0.
- `use` of a third-party package (`use stats`) before release 2.0, which brings the package manager; the project's own modules are brought in as `use functions::<name>`.
- A `case` row by row whose arms give an opaque column, which no release computes on.
- An operator on an opaque column, which is carried through the row verbs and nothing else (section 4.3 of the Language Reference).

## Example
```
> let m = model { quality =~ q1 + q2 + q3 }
error[Z0304]: a `model { }` block is not available in this release
  = help: latent-variable models arrive with release 1.12
```

## Fix
Wait for the release named, or write the analysis with what this release has.
