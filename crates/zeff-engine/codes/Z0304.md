# Z0304 — not available in this release

## Meaning
The grammar has this construct, but this release of the engine does not run it yet; the message says which release brings it. Nothing is wrong with the script.

## Common causes
- A `dag { }` block before release 0.10.0; a `model { }` block, or a label written with `as` inside one, before release 1.3. These are the checker's remaining refusals: `if`, `case`, `for`, `fn` and `use functions::…` run from 0.5.0.
- `use` of a third-party package (`use stats`) before the package manager that follows 1.0; the project's own modules are brought in as `use functions::<name>`.
- A `case` row by row whose arms give a column of a type this release does not build.
- An operator on a Date or Category column before the package that computes on it.

## Example
```
> let g = dag { educ -> wage }
error[Z0304]: a `dag { }` block is not available in this release
  = help: causal graphs arrive with release 0.10.0
```

## Fix
Wait for the release named, or write the analysis with what this release has.
