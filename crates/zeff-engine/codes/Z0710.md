# Z0710 — the project pins another engine

## Meaning
`zeff.toml` pins an exact engine version, and this engine is another. The pin keeps results reproducible, so the engine refuses rather than running with a different version (exit code 4).

## Common causes
- A project made with an older or newer Zeff.
- An engine updated without updating the pin.

## Example
```
> zeff run
error[Z0710]: this project needs Zeff 0.1.0, but this is Zeff 0.2.0
```

## Fix
Install the pinned engine (the launcher does this from 0.9.0), or update the pin in `zeff.toml` knowingly.
