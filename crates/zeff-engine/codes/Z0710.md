# Z0710 — the project's engine is not the one at hand

## Meaning
`zeff.toml` pins an exact engine version, so that a project re-runs unchanged, and that engine is not available: either it is not installed and cannot be installed (the run is frozen or offline, or there is no such version), which the launcher says, or an engine was run directly on a project that pins another, which the engine says. Nothing is run on another version (exit code 4). The same code is raised outside a project when the default engine, or any engine at all, is missing.

## Common causes
- A project made with an older or newer Zeff than is installed.
- An engine removed while a project still pins it.
- An engine's own binary run directly on a project that pins another, without the launcher.
- A new machine with the launcher and no engine yet.

## Example
```
> zeff run
error[Z0710]: this project needs Zeff 0.9.1, which is not installed
  = help: `zeff engine install 0.9.1` installs it; the engine installed is 0.9.0; the pin is in `/home/ada/study/zeff.toml`
```

## Fix
Install the pinned engine with `zeff engine install <version>`, or update the pin in `zeff.toml` knowingly: a result made by one version is not promised by another. Outside a project, `zeff engine install` installs the newest engine and `zeff engine default <version>` chooses which one runs.
