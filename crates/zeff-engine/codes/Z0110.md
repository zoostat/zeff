# Z0110 — a script-only function inside a function

## Meaning
A function's result depends on its arguments alone, so it gives the same result wherever it is called and may be cached (section 3.7, "Effects"). `import`, `save`, `export`, `seed`, `today`, `now` and `timer` read or write outside the arguments, so they are allowed in a script and not inside a function.

## Common causes
- A function that imports its own data instead of taking a frame.
- A function that saves or exports its result instead of returning it.

## Example
```
> fn load() -> Frame { import("data/wages.csv") }
error[Z0110]: `import` is allowed only in a script, not inside the function `load`
  = help: a function's result depends on its arguments alone, so it may be cached; import the data in the script and pass the frame in
```

## Fix
Import in the script and pass the frame as an argument; return the result and let the script save or export it.
