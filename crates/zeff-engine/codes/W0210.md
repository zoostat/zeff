# W0210 — values of `bin` outside every interval

## Meaning
`bin(x, breaks:)` gives each value the interval it falls in among the breaks. A value below the first break or above the last, or equal to an end that is open, falls in none and becomes `NA`, as R's `cut` makes it `NA`; this warning gives the count so that a range chosen too narrow is not passed over in silence. A value that was `NA` already is not counted.

## Common causes
- Breaks that do not reach the data: `breaks: [0, 10, 20]` on wages above 20.
- A value exactly on the first break under `closed: right`, where `(a, b]` excludes `a`, or on the last break under `closed: left`.
- Breaks written for another file's range.

## Example
```
> let pay = frame(wage = [8.5, 18.08, 26.39])
> pay.add(band = bin(wage, breaks: [10, 20]))
frame · 3 rows × 2 variables

       wage   band
  1     8.5   NA
  2   18.08   (10,20]
  3   26.39   NA
warning[W0210]: `bin`: 2 rows outside every interval became NA (line 2)
  = help: the intervals run from 10 to 20; `-Inf` and `Inf` as the first and last breaks keep every value
```

## Fix
Add `-Inf` and `Inf` as the first and last breaks, `breaks: [-Inf, 10, 20, Inf]`, so that every value has an interval; or widen the breaks to the range `describe` shows; or keep the `NA`s when values outside the range are meant to be left out.
