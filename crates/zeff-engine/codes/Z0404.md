# Z0404 — no such argument

## Meaning
The function has no argument of that name, a definition was given to a function that takes options, or the receiver was written as an option.

## Common causes
- A misspelt option name.
- An option of a later release.
- `by:` on a function that does not take it yet.
- A spread, `..opts`, whose record holds a field that names no argument of the function.

## Example
```
> wages.mean(wage, by: id)
error[Z0404]: `mean` has no argument called `by`
  = help: usage: `data.mean(var)`
```

## Fix
Use the arguments the usage line shows; `zeff help <function>` explains each.
