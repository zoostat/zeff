# Z0108 — a function that calls itself

## Meaning
A function may not call itself, directly or through other functions (section 3.7, "Recursion"). Iteration in Zeff is `for` over a known length and `iterate` to convergence with a bound, so that every script finishes and the engine needs no call-depth limit. The message shows the cycle.

## Common causes
- A recursive definition carried over from another language: `fn fact(n: Int) -> Int { n * fact(n - 1) }`.
- Two helpers that call each other.

## Example
```
> fn ping(n: Int) -> Int { pong(n) }
> fn pong(n: Int) -> Int { ping(n) }
error[Z0108]: a function may not call itself: `ping` calls `pong`, which calls `ping`
  = help: iteration is `for` and `iterate` (section 5.5), so that every script finishes
```

## Fix
Write the repetition as a `for` loop over a range or a list, or as `iterate` with a stopping rule and `max:`.
