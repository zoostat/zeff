# Z0001 — the script stopped itself with error()

## Meaning
The script called `error(message)`: the analysis found a condition its author decided it must not continue under, and it stopped there with the message written. Nothing after that statement ran; the statements before it did. There is no `try`/`catch` in Zeff: an analysis that fails at the top level stops where it fails (section 5.4 of the Language Reference).

## Common causes
- A check the author wrote, such as a sample with no treated units or a file with the wrong columns.
- An `assert` that failed (from release 0.5.0).

## Example
```
> error("the sample has no treated units")
error[Z0001]: the sample has no treated units
```

## Fix
Read the message: it is the author's own words about what went wrong with the data or the run; fix the data, or the condition, and run again. The exit code is 1.
