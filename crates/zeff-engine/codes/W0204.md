# W0204 — a division by zero gave an infinity

## Meaning
A Float divided by zero is `Inf` or `-Inf`, which Zeff keeps as a value (section 4.1 of the Language Reference) and announces, with the count of rows for a column.

## Common causes
- A ratio whose denominator is zero in some rows.
- `log(0)`, which is `-Inf`.
- A reducer over a column holding both `Inf` and `-Inf`, whose mean is `NA`.

## Example
```
> 1 / 0
Inf
warning: division by zero gave Inf (line 1)
```

## Fix
Test the divisor first, as in `b != 0 && a / b > 1`; on a frame, keep the rows with a divisor: `where(b != 0)`.
