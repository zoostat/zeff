# Z0413 — a distribution parameter or probability outside its domain

## Meaning
A distribution was given a parameter outside its domain (a standard deviation that is not positive, degrees of freedom that are not positive, a probability outside [0, 1], or `NA`), or `quantile` was given a probability outside [0, 1].

## Common causes
- `dist.normal(sd: 0)` or `dist.normal(sd: -2)`: the standard deviation must be positive.
- A parameter computed from data that came out `NA`.
- `d.quantile(1.5)`: a probability lies between 0 and 1.

## Example
```
> dist.normal(sd: 0)
error[Z0413]: `sd` of `dist.normal` must be a positive number, but this is 0
  = help: `zeff help dist.normal` gives the domain of every parameter
```

## Fix
Give a value inside the domain the help page states; check the computation that produced an `NA` parameter.
