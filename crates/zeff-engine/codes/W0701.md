# W0701 — a data root's file has changed since the last run

## Meaning
A file read from a data root (a folder declared under `[data]` in `zeff.toml`) is not the file the last run read: its contents hash differently, and the two modification times are given. The run goes on with the file as it is now; the warning says that its results may differ from the last run's for that reason. Data roots are shared, read-only folders, so a change there is made outside the project (section 2 of the Engine and Project Specification, "Data roots"). A file under the project's own folder, or a shipped `zeff:` file, is never warned about.

## Common causes
- A shared survey file was refreshed or re-exported since the project last ran.
- The root was pointed at another folder in `zeff.toml`, so the same name is another file.

## Example
```
> let lfs = import("lfs:wages.csv")
warning[W0701]: `lfs:wages.csv` has changed since the last run: it was read on 2026-11-01 09:14:03, and the file is now from 2026-11-02 08:30:12
  = help: the results may differ from the last run's; the run records of release 0.11.0 will show how
```

## Fix
Nothing, if the change is intended: the next run reads the new file without the warning. Otherwise restore the file, or copy a fixed version into the project's `data/` folder.
