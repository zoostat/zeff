# Z0401 — an argument of the wrong type

## Meaning
An argument, a receiver or a definition has a type the function does not take: text where a variable is wanted, a number as a receiver, a Str column given to `mean`, an option value of the wrong kind.

## Common causes
- `wages.mean("wage")`: the variable goes without quotes.
- `mean` on a text column.
- `delim: 5`, `skip: -1`, `types: {wage: 1}`.

## Example
```
> wages.mean("wage")
error[Z0401]: `var` of `mean` must be a Var, but this is a Str
  = help: name a variable of the frame, without quotes
```

## Fix
Give the kind of value the help line names; `zeff help <function>` shows every argument's type.
