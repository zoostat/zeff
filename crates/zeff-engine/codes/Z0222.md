# Z0222 — a mapping key, or a record field, written twice

## Meaning
A mapping's keys are unique; the same key appeared twice, in the literal or after computing the keys. A record's field names are unique too: a field written twice, or supplied by two spreads (`{..a, ..b}` where both have the field), is the same error. A field written out beside a spread is not: it overrides the spread's field.

## Common causes
- A copied line in a long mapping of codes to labels.
- Two option records spread into one that share a field; write the field out to say which value is meant.

## Example
```
> [1 => "a", 1 => "b"]
error[Z0222]: a mapping's keys are unique, but this key is written twice
```

## Fix
Keep one entry for the key.
