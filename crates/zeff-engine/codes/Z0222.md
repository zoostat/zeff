# Z0222 — a mapping key written twice

## Meaning
A mapping's keys are unique; the same key appeared twice, in the literal or after computing the keys.

## Common causes
- A copied line in a long mapping of codes to labels.

## Example
```
> [1 => "a", 1 => "b"]
error[Z0222]: a mapping's keys are unique, but this key is written twice
```

## Fix
Keep one entry for the key.
