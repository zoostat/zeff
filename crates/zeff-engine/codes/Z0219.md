# Z0219 — a value whose type is unknown

## Meaning
A bare `NA`, an empty list or a list of nothing but `NA` takes its type from where it stands; where nothing gives one, such as `let x = NA` or `frame(x = [])`, Zeff cannot know what the value is.

## Common causes
- `let x = NA`.
- A column built from an empty list or from `NA` alone.

## Example
```
> let x = NA
error[Z0219]: `NA` alone has no type, so `x` cannot be bound to it
```

## Fix
Give the value its type where it is used, as in `to(NA, Int)` (release 0.5.0), or give the list at least one value.
