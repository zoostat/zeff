# W0511 — a path that is no effect is open

## Meaning
`check` held a fitted model against a causal graph and found that the regressors are not a sufficient adjustment set: between the exposure and the outcome a path is open that is no part of the effect, so the coefficient of the exposure mixes the effect with something else. The path is named. It is a back-door path that no regressor closes, or a path that a regressor opens by being a collider on it (a common effect of the variables on either side) or a descendant of one, or a path that the selection of the data opens. When no set of observed variables could close every such path, the warning says that instead, with what stands in the way. The fit is not changed and not refused.

## Common causes
- A common cause of the exposure and the outcome left out of the model.
- A collider among the controls: a variable that both sides act on, added because it is related to both.
- A common cause that is not observed, so that no choice of controls will do.
- A sample selected on a variable that the exposure and the outcome, or their causes, both act on.

## Example
```
> let g = dag {
>     training -> productivity
>     age -> training
>     age -> productivity
> }
> let m = dataset(staff).reg(productivity ~ training)
> let c = m.check(g, exposure: training)
warning[W0511]: the regressors leave the back-door path training ← age → productivity open
  = help: { age } is a sufficient adjustment set; `adjustment_sets` lists every one
```

## Fix
Add the variables of a sufficient set, which the help names and `adjustment_sets` lists, and drop a collider the warning names. When no sufficient set exists, adjustment cannot give the effect: an instrument for the exposure (`ivreg`) or a front-door design may.
