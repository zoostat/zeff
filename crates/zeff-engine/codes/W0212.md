# W0212 — tied values in the Kolmogorov–Smirnov test

## Meaning
Some values of the variable given to `ks_test` are equal to one another. The distribution of D, exact or limiting, is derived for a continuous distribution, under which two values coincide with probability zero; with ties the p-value is approximate, and the limiting distribution is used whatever the sample size, as R does. The warning gives the count of values that share their value with another.

## Common causes
- Values recorded to few decimals, such as rounded wages or hours.
- A discrete variable, such as a count, tested against a discrete distribution.

## Example
```
> wages.ks_test(hours, dist.normal(mean: 40, sd: 10))
warning[W0212]: 17,850 of the 17,923 values of `hours` tie with another; the Kolmogorov–Smirnov test assumes a continuous distribution, so its p-value is approximate
  = help: the asymptotic distribution is used; for a discrete variable, `chi2_test` with `p:` compares the frequencies instead
```

## Fix
Nothing, when the ties are a few rounded values: read the p-value as approximate. For a discrete variable, compare the frequencies with `chi2_test` and `p:` instead.
