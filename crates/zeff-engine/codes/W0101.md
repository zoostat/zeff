# W0101 — a binding hides a built-in function

## Meaning
A `let` gave a name that a package's function already has, such as `mean`. The binding is made, and the function stays reachable under its full name, but a reader may take one for the other.

## Common causes
- A short name chosen without knowing a function has it.
- A variable called `mean`, `sum` or `median` that holds a computed value.

## Example
```
> let mean = 3
warning: `mean` hides the function `data::mean` (line 1)
```

## Fix
Choose a name that is not a function's, such as `avg_wage`; if the binding must keep the name, call the function as `data::mean(...)`.
