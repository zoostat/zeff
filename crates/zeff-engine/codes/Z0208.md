# Z0208 — comparison is not defined for this value

## Meaning
`==` and the other comparisons work on single values: numbers, text, Bool, dates and `NA`. A list, record, mapping, frame or table cannot be compared as a whole.

## Common causes
- `[1, 2] == [1, 2]`.
- Comparing two frames to see whether they are the same.

## Example
```
> [1] == [1]
error[Z0208]: `==` is not defined for a List<Int>
```

## Fix
Compare the items one by one, or the values that matter; `equal(a, b)` for structural equality arrives with 0.5.0.
