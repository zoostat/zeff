# Z0211 — an Int overflowed

## Meaning
An Int result does not fit in 64 bits. Zeff never wraps around silently: the operation, and the row for a column, is named.

## Common causes
- A product or sum of large whole numbers.
- A running total over many rows.

## Example
```
> 9223372036854775807 + 1
error[Z0211]: Int overflow: 9223372036854775807 + 1 does not fit in 64 bits
```

## Fix
Compute in Float, which holds larger magnitudes with 53 bits of precision: multiply by `1.0` first.
