# Z0216 — text that is no level of a category, or a label given for a labelled number

## Meaning
A category compares with text by its levels, so text that is none of its levels cannot be compared with it. An Int variable that carries value labels compares as the number it holds: its labels are for printing, and text given against it is refused with the code it stands for.

## Common causes
- `industry == "Retial"`: a misspelt level.
- `female == "female"`: the variable holds 0 and 1 and prints their labels.
- A text column compared by order with a category, where one row holds text that is no level.

## Example
```
> wages.where(female == "female")
error[Z0216]: "female" is a value label, and the variable compares as a number
  = help: write `== 1`: 1 is the code labelled "female"
```

## Fix
Write one of the category's levels in quotes (`levels(x)` lists them), or the code behind the label.
