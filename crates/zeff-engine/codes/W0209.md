# W0209 — a method on a value that may have failed

## Meaning
A binding made from `attempt` may hold a `Failed` value. Calling a method on it, `m.coef(x)`, would stop the script with Z0220 when the attempt failed, so the checker says so before the script runs. The warning does not appear when the call is guarded: inside `if !m.is(Failed) { ... }`, or after `if m.is(Failed) { ... }` whose block ends in `continue`, `break`, `return` or `error` (section 3.7, "Narrowing").

## Common causes
- `let m = attempt(d.reg(y ~ x))` followed straight away by `m.coef(x)`.
- A guard that tests the wrong binding, or does not leave the block.

## Example
```
> let m = attempt(w.reg(log(wage) ~ educ))
> m.coef(educ)
warning[W0209]: `m` may hold a failed value, so `coef` may stop the script
  = help: guard the call: `if m.is(Failed) { ... }` with a `continue`, `break` or `error` inside, or `if !m.is(Failed) { m.coef(...) }`
```

## Fix
Guard the call with `m.is(Failed)`, or drop `attempt` where a failure should stop the script.
