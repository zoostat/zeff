# Z0306 — an interaction outside a formula

## Meaning
`:` means an interaction and is allowed only inside a formula or a `Terms` argument such as `fe:`.

## Common causes
- `a : b` written for multiplication.

## Example
```
> 2 : 3
error[Z0306]: `:` is an interaction and belongs in a formula
```

## Fix
Write `a:b` inside a formula or a `fe:` argument; multiplication is `*`.
